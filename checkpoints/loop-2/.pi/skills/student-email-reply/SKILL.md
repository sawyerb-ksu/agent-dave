# Student email reply

1. Read the email. Note the student's question and any
   deadline they mention.
2. If you need a fact you don't have (a date, a policy,
   a room), ask the user instead of guessing.
3. Draft a reply under 150 words: thank them, answer
   the question, give one next step.
4. Show the draft. Save it to drafts/YYYY-MM-DD-name.md
   only if the user asks.

## Rules
- Never promise a grade change, extension or exception. Say who decides.
- Use the student's first name. Sign off with the user's name if you know it.
- If the email sounds urgent or upsetting, say so to the user before drafting.
