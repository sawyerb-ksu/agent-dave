# Skill ideas

A good skill is a task you do often, the same way each time. Pick one, copy `templates/my-skill` into `.pi/skills/`, and start from the description given here.

Want more? [awesomeskill.ai](https://awesomeskill.ai/) catalogs open-source skills by category. Read a few for ideas, then write your own in your own words: a skill you understand is easier to fix when it misfires.

| Role | Skill | Description to start from |
|---|---|---|
| Faculty | `rubric-feedback` | Give feedback on a student draft against a rubric, one comment per criterion. Use when the user pastes a draft and a rubric. |
| Faculty | `syllabus-check` | Check a syllabus for required sections, dates and policies. Use when the user shares a syllabus to review. |
| Staff | `event-announcement` | Write a short event announcement with date, time, place and who it's for. Use when the user asks to announce or promote an event. |
| Staff | `student-email-reply` | Draft a reply to a student email. Use when the user pastes a student email. *(Finished example in `checkpoints/loop-2/`.)* |
| Staff | `weekly-update` | Turn bullet notes into a short weekly update for a team. Use when the user asks for a status update or weekly summary. |
| Students | `study-plan` | Turn a list of exams and due dates into a day-by-day study plan. Use when the user shares deadlines or asks for a study schedule. |
| Students | `paper-summary` | Summarize a paper in five bullets plus one question to ask in class. Use when the user pastes a paper or abstract. |
| Researchers | `methods-check` | Review a methods section for missing details someone would need to repeat the study. Use when the user shares a methods draft. |
| Researchers | `lab-entry` | Turn rough notes into a lab-notebook entry: date, goal, method, observations, next step. Use when the user shares notes from an experiment. |
| Anyone | `decision-memo` | Lay out a decision as options, pros, cons and a recommendation. Use when the user is weighing a choice. |

Tip: the description decides when DAVE uses the skill, so say what it does *and* when to use it.
