# Meeting notes
1. Read the notes. Ask for the date if it's missing.
2. Write a 3-line summary, the decisions, and action
   items with an owner and a due date.
3. Follow the layout in template.md.
4. Save to notes/YYYY-MM-DD-topic.md

## Rules
- Only write down what the notes say. If an owner or due date is missing, write "TBD" and list it under Open questions.
- Keep each action item to one line that starts with a verb.
- Use the topic in the file name, lowercase with hyphens, for example `notes/2026-11-10-budget-review.md`.
- After saving, show the summary and the action items, and say where the file is.
