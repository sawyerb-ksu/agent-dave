# Research brief
1. Restate the question in one line. If it's too broad
   for one page, ask the user to narrow it first.
2. Use the fetch tool to read 3 to 5 good sources:
   official pages, papers or reputable news. Note the
   URL of each one.
3. Write the brief using the layout in template.md.
4. Save to briefs/topic.md

## Rules
- Every finding needs a source from step 2. Don't add facts you didn't read.
- If sources disagree, say so instead of picking one.
- If a page won't load, say which one and move on to another source.
- Keep it to one page: about 400 words plus the source list.
